## Overview

FLASH-Q is a console-based Java application designed to aid users in learning and self-assessment by creating, managing, and taking quizzes with flashcards.

## Problem

Students need an effective tool for self-assessment and memorization. Existing solutions are often overly complex or lack focus on simplicity.

## My Role

Sole developer. Designed and implemented the entire application using object-oriented principles.

## Objectives

- Create an intuitive flashcard management system
- Implement quiz generation and scoring
- Enable persistent storage of flashcard decks

## Tech Stack

- **Language:** Java
- **Paradigm:** Object-Oriented Programming
- **Storage:** File-based serialization
- **Interface:** Console-based UI

## Features

- Create, edit, and delete flashcard decks
- Generate random quizzes from deck content
- Score tracking and performance analytics
- Export/import deck functionality

## Development Process

Started with class design and UML diagrams. Implemented core flashcard logic first, then quiz engine, then persistence layer.

## Challenges Faced

Designing flexible data structures for various flashcard types. Balancing console UI usability with limited interface options.

## Lessons Learned

Importance of separation of concerns in console applications. Value of iterative testing with real users.
