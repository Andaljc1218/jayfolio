## Overview

FoundIT is a job matching platform designed to connect students with internship and entry-level opportunities. The platform streamlines the job search process by providing curated listings, application tracking, and employer profiles.

## Problem

Students often struggle to find relevant internship opportunities scattered across multiple platforms. Employers face difficulty reaching qualified candidates early in their careers.

## My Role

Sole developer responsible for full-stack implementation, database design, and deployment.

## Objectives

- Create a centralized platform for student job seekers
- Enable employers to post and manage opportunities
- Implement matching algorithm based on skills and preferences

## Tech Stack

- **Frontend:** Next.js 15, TypeScript, Tailwind CSS
- **Backend:** Next.js API Routes
- **Database:** PostgreSQL with Prisma ORM
- **Authentication:** NextAuth.js
- **Deployment:** Vercel

## Features

- User authentication for students and employers
- Job posting and management dashboard
- Skill-based matching algorithm
- Application tracking system
- Responsive design for mobile and desktop

## Development Process

Started with requirement gathering and database schema design. Built authentication first, then core job listing features, followed by the matching algorithm.

## Challenges Faced

Designing an effective matching algorithm that balanced relevance with diversity of results. Optimizing database queries for large datasets.

## Lessons Learned

Importance of iterating on algorithms with real user data. Value of clean database schema design for maintainability.
