## Overview

FoundIT is a job matching platform designed to connect students with internship and entry-level opportunities. The platform streamlines the job search process by providing curated listings, application tracking, and employer profiles.

## Problem

Students often struggle to find relevant internship opportunities scattered across multiple platforms. Employers face difficulty reaching qualified candidates early in their careers. The traditional job board model doesn't cater specifically to students' unique needs — they need mentorship, flexible hours, and learning-focused roles.

## Solution

FoundIT centralizes student-friendly opportunities in one place, with a matching algorithm that considers skills, location, and availability. The platform provides tailored dashboards for both students and employers, with built-in application tracking and communication tools.

## Key Features

- **User Authentication** — Role-based access for students, employers, and admins
- **Job Matching Algorithm** — Skill-based matching with preference ranking
- **Application Dashboard** — Track applications, deadlines, and interview schedules
- **Employer Profiles** — Company information, culture, and opportunity listings
- **Responsive Design** — Optimized for mobile and desktop workflows

## Technology Stack

- **Framework:** Next.js 15 (App Router, Server Components)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Database:** PostgreSQL with Prisma ORM
- **Authentication:** NextAuth.js
- **Deployment:** Vercel

## Development Process

Started with requirement gathering and database schema design. Built authentication first, then core job listing features, followed by the matching algorithm. Used a feature-branch workflow with code reviews.

## Challenges

Designing an effective matching algorithm that balanced relevance with diversity of results. Optimizing database queries for large datasets. Implementing real-time notifications for application status changes.

## Lessons Learned

Importance of iterating on algorithms with real user data. Value of clean database schema design for maintainability. The significance of accessibility in application interfaces for users with disabilities.

## Future Improvements
