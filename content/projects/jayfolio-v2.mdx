## Overview

JayFolio v2 is a complete redesign of my personal portfolio, emphasizing clean design, technical documentation-style layout, and engineering quality.

## Problem

The previous portfolio used a gaming-inspired aesthetic that no longer represented my professional goals. It needed a complete architectural rebuild to meet modern web standards.

## My Role

Sole designer and developer. Responsible for architecture decisions, UI/UX design, and implementation.

## Objectives

- Rebuild with Next.js 15 and TypeScript
- Achieve Lighthouse 95+ scores
- Implement case study project pages
- Optimize for performance and accessibility

## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Motion:** Framer Motion
- **Content:** MDX for project case studies
- **Deployment:** Vercel

## Features

- Server Components for optimal performance
- MDX-based project case studies
- Staggered scroll animations
- Fully responsive design
- SEO-optimized with dynamic metadata
- Dark mode support

## Development Process

Followed a phased approach: analysis, architecture, wireframes, design system, incremental build, and optimization.

## Challenges Faced

Balancing minimal design with engaging interactions. Optimizing bundle size while maintaining rich typography.

## Lessons Learned

Value of planning before implementation. Importance of performance budgets in design decisions.
