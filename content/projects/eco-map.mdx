## Overview

Eco-map is an Environmental Waste Management and Tracking System. A web-based platform for efficient waste management and community coordination.

## Problem

Waste management in communities lacks transparency and coordination. Residents and officials struggle to track waste collection schedules and report issues effectively.

## My Role

Full-stack developer responsible for frontend, backend, and database implementation.

## Objectives

- Centralize waste collection schedules
- Enable residents to report issues
- Provide analytics dashboard for officials

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL with XAMPP
- **Maps:** Leaflet.js for location tracking

## Features

- Interactive waste collection map
- Issue reporting system
- Admin dashboard for barangay officials
- Collection schedule notifications

## Development Process

Built using traditional PHP MVC pattern with MySQL database. Focused on usability for non-technical users.

## Challenges Faced

Integrating real-time map updates without external APIs. Designing intuitive interfaces for diverse user groups.

## Lessons Learned

Value of simplicity in government/community software. Importance of offline-friendly design for rural areas.
